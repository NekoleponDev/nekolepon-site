# Nekolepon Studio Website

React + Vite multi-page website with Tailwind CSS, reusable components, and responsive neo-brutalist styling.

## Project structure

- `src/main.jsx` — React entry point
- `src/App.jsx` — shared layout and page routes
- `src/pages/` — Home, Games, Game Detail, Studio, Contact, and Not Found pages
- `src/components/` — reusable navigation, footer, game cards, artwork, marquee, recipe, and contact sections
- `src/data/games.js` — source of truth for the game catalogue
- `src/global.css` — Tailwind directives, base rules, and design-specific styles
- `tailwind.config.js` — Tailwind theme
- `postcss.config.js` — Tailwind/PostCSS integration

## Add a game

Add one object to the `games` array in `src/data/games.js`:

```js
{
  slug: "new-game",
  name: "New Game",
  status: "IN DEVELOPMENT",
  platform: "PC",
  genre: ["ADVENTURE", "NARRATIVE"],
  description: "Full game description.",
  shortDescription: "Short card and artwork description.",
  tagline: "A short line for the game detail page.",
  featured: true,
  artwork: "window"
}
```

Use a unique, URL-friendly `slug`. The game automatically appears on the Games page, gets a detail route at `/games/new-game`, and appears on the homepage when `featured` is `true`. Set `featured: false` to keep it in the catalogue only.

This is a static-site content workflow: adding or editing games requires a Git commit and a Vercel deployment. A live admin dashboard that saves content without a deployment needs a CMS or database and authentication.

## Development

```bash
npm install
npm run dev
npm run build
npm run preview
``

## Vercel

- Build command: `npm run build`
- Output directory: `dist`
- `dist/` is generated by Vite and ignored by Git; do not commit it.
- React Router paths are handled by `vercel.json`.
